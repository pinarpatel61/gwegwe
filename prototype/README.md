# otkrovenno.online — прототип всего сайта (мобильный + ПК)

Кликабельный прототип нового дизайна на основе варианта 1 «Свайп» из `home-prototypes-20261011`.
Без сборки и зависимостей: открывается двойным кликом.

## Как смотреть

| Файл | Что это |
|---|---|
| `index.html` | Карта прототипа: принципы, список всех экранов, превью телефон + ПК, ссылки на каждый экран |
| `app.html` | Сам прототип (одна страница, hash-маршруты `#/...`) |
| `app.css` | Дизайн-токены и все компоненты; ПК-лейаут — в `@media (min-width:980px)` |
| `app.js` | Экраны (по одной функции `V.*` на экран), листы, экономика, роутер |
| `data.js` | Анкеты и фото из архива (как есть) |
| `content.js` | Чаты, уведомления, подарки, пакеты, FAQ, заявки — контент прототипа |
| `shots/` | Скриншоты всех экранов `*-m.png` (390×844) и `*-d.png` (1440×900) |

- Мобильная версия: открыть `app.html` на телефоне или сузить окно уже 980px.
- Тёмная тема: `app.html?theme=dark#/` или в настройках → Оформление.
- Гостевой сценарий: `app.html?guest=1#/` (гейт при первом лайке/сообщении).
- Открыть лист сразу: `?open=filters|chat|gift|stickers|extend|menu|gate|topup` (пример: `#/chat/c1?open=gift`).
- Шаг оплаты: `#/checkout/pack:p3?step=2`.

Клавиши на ПК: `←` пропустить · `→` нравится · `↑` искра · `Enter` написать · `Backspace` вернуть · `Esc` закрыть лист.

## Экономика в прототипе (как на сайте, октябрь 2026)

Пакеты чатов €7 / €18 / €28 / €52 (1 / 3 / 5 / 10 чатов, 10 сообщений в чате), баланс € — подарки, искры, стикер-паки.
Оплата USDT (TRC20, BEP20, Solana, TON) и Binance Pay; карта — «Скоро». Состояние живёт в памяти страницы и сбрасывается при перезагрузке.
